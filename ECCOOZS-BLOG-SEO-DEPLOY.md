## Optional social profile environment variables
Set only the profiles that actually exist. The Journal automatically hides missing ones.

```
NEXT_PUBLIC_ECCOOZS_INSTAGRAM=https://...
NEXT_PUBLIC_ECCOOZS_FACEBOOK=https://...
NEXT_PUBLIC_ECCOOZS_TIKTOK=https://...
NEXT_PUBLIC_ECCOOZS_YOUTUBE=https://...
NEXT_PUBLIC_ECCOOZS_THREADS=https://...
NEXT_PUBLIC_ECCOOZS_X=https://...
```

## Immediately after deployment
1. Open `https://eccoozs.com/robots.txt` and confirm it loads.
2. Open `https://eccoozs.com/sitemap.xml` and confirm all blog URLs appear.
3. In Google Search Console, submit `https://eccoozs.com/sitemap.xml`.
4. Use URL Inspection on `/`, `/welcome`, `/blog`, and each launch article; request indexing.
5. Keep every social profile's name, website URL, and bio consistent with ECCOOZS branding.
6. Publish new useful articles steadily; do not keyword-stuff or mass-produce thin pages.
