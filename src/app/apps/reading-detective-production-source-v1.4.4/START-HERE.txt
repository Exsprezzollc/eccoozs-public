READING DETECTIVE v1.4.4 — START HERE

You already created:
  eccoozs-public\apps\reading-detective

Leave that folder in place.

1. Extract this production-source ZIP somewhere OUTSIDE eccoozs-public.
2. Double-click:
     INSTALL-READING-DETECTIVE.cmd
   (This launches the PowerShell build script for you.)
3. The script builds Reading Detective and places ONLY the production output into:
     %USERPROFILE%\Downloads\eccoozs-public\apps\reading-detective

If your eccoozs-public folder is somewhere else, see INSTALL-INSTRUCTIONS.txt.

Do not copy src/, scripts/, package.json, or this source folder into eccoozs-public manually.
