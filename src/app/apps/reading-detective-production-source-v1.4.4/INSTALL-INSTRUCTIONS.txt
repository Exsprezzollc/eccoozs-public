ECCOOZS READING DETECTIVE — PRODUCTION DROP-IN
Version 1.4.4

TARGET FOLDER
  eccoozs-public\apps\reading-detective

DO NOT manually copy the source files into that target folder.

WINDOWS BUILD + INSTALL
1. Extract this ZIP somewhere OUTSIDE eccoozs-public.
2. Open the extracted reading-detective-production-source-v1.4.4 folder.
3. Right-click BUILD-AND-INSTALL-READING-DETECTIVE.ps1 and choose Run with PowerShell.

The script will:
- install dependencies
- run the engineering verification suite
- create the real Vite production build
- back up any existing Reading Detective files
- copy only dist/ production files into eccoozs-public\apps\reading-detective

If eccoozs-public is not in your normal Downloads folder, open PowerShell in this folder and run:
  .\BUILD-AND-INSTALL-READING-DETECTIVE.ps1 -EccoozsPublicPath "C:\path\to\eccoozs-public"

SUCCESS LOOKS LIKE
  eccoozs-public\apps\reading-detective\index.html
  eccoozs-public\apps\reading-detective\assets\...
  eccoozs-public\apps\reading-detective\manifest.webmanifest

PUBLIC PATH
